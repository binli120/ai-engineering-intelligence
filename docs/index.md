- AI coding workflows and assistants
- Agent architecture and development frameworks
- Model Context Protocol

- Evaluation, observability, security, and deployment
- High-quality tutorials and runnable examples

## Current focus

The MVP begins with two complementary agent frameworks:

- **OpenAI Agents SDK** for lightweight agent primitives, tools, handoffs, guardrails, sessions, and tracing.
- **LangGraph** for explicit stateful orchestration, persistence, branching, human-in-the-loop workflows, and durable execution.
